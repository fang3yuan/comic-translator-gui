# مترجم الكوميكس والمانهوا (إنجليزي ← عربي)

برنامج يعمل على جهازك: تسحب صفحات الكوميكس إليه، فيقرأ النص الإنجليزي، ويمسحه، ويترجمه، ويكتب العربية مكانه داخل الفقاعة.

> English technical docs: [README_EN.md](README_EN.md)

---

## ⚡ التثبيت في 3 خطوات (أول مرة فقط)

### 1) ثبّت بايثون (مرة واحدة)
- حمّل **Python 3.11 أو أحدث** من https://www.python.org/downloads/
- **مهم جدًا (ويندوز):** في أول شاشة للتثبيت ضع علامة ✔ على **Add python.exe to PATH** ثم Install.
- ماك: نفس الرابط. لينكس: غالبًا موجود، وتحتاج `sudo apt install python3-tk`.

### 2) شغّل البرنامج بنقرتين
فك ضغط المجلد، ثم:

| نظامك | ماذا تفعل |
|-------|-----------|
| **ويندوز** | انقر مرتين على **`Start.bat`** |
| **ماك / لينكس** | افتح الطرفية داخل المجلد واكتب: `bash start.sh` |

في **أول مرة** سينزّل المكتبات تلقائيًا (من 2 إلى 5 دقائق، حوالي 150 ميغابايت). لا تغلق النافذة السوداء. بعدها يفتح البرنامج، وفي المرات القادمة يفتح فورًا.

### 3) اضغط زر التثبيت الكبير
عند أول فتح تظهر نافذة **Setup**. اضغط **⬇ Install everything needed** (تثبيت كل شيء). يحمّل نموذج المسح الذكي LaMa (حوالي 200 ميغابايت) ويفحص كل شيء. تجد علامة ✔ بجانب كل مكوّن جاهز.
تستطيع فتح هذه النافذة في أي وقت من الزر البنفسجي **🛠 Setup / Install**.

> بعد تثبيت دعم السحب والإفلات لأول مرة، أغلق البرنامج وافتحه مرة ثانية.

---

## 🖱️ الاستخدام

1. **اسحب** صور الصفحات (أو مجلدًا كاملًا) وأفلتها داخل نافذة البرنامج. (أو اضغط **Add Images / Add Folder**.)
2. اضغط **▶ Translate this page** لصفحة واحدة، أو **▶▶ Translate all pages** لكل الصفحات.
3. النتائج تُحفظ تلقائيًا في مجلد **`translated`** بجانب صورك. اضغط **📂 Open output folder** لفتحه.

**لتعديل النتيجة:**
- اسحب المربع الذي يظهر على الصفحة لتحريكه، واسحب زواياه لتغيير مساحة النص.
- تبويب **Blocks**: عدّل الترجمة بيدك، غيّر نوع النص، أو أعد ترجمته.
- تبويب **Fonts & Style**: اختر الخط واللون والحدود لكل نوع (حوار / سرد / صوت / همس).
- عجلة الفأرة للتكبير، والسحب للتحريك، وزر **Side-by-side** لمقارنة الأصل بالنتيجة.

## 🛠️ مشكلة: «فشلت الترجمة»

1. اضغط **Setup ← Test translation** (أو من تبويب Translation زر **🔎 Test translation**).
2. سيخبرك لكل مزوّد ✔ أو ✘ **مع السبب بالعربي**:

| الرسالة | المعنى والحل |
|---------|--------------|
| لا يوجد اتصال بالخدمة | الإنترنت مقطوع، أو الـVPN/الجدار الناري/مضاد الفيروسات يحجب. جرّب إغلاق الـVPN أو فتح الموقع في المتصفح. |
| تجاوزت حد الطلبات (429) | انتظر دقائق، أو زد **Seconds between requests** في تبويب Translation. |
| الخدمة حجبت الطلب (403) | جرّب مزوّدًا آخر أو VPN. |
| مفتاح DeepL فارغ | هذا المزوّد يحتاج مفتاحًا مجانيًا من deepl.com. الأسهل استخدام Google أو MyMemory. |
| غير مثبّت (Local) | هذه الترجمة بدون إنترنت وتحتاج حزمة كبيرة (700 ميغابايت). اضغط Install في Setup. |

**بالإعدادات الافتراضية:** يبدأ بـ Google، وإن فشل ينتقل تلقائيًا إلى MyMemory (مجاني بدون مفتاح). كلاهما يحتاج إنترنت.
البرنامج لا يجرّب مزوّدًا فشل من جديد في كل صفحة، فلا يتأخر.

## ❓ أسئلة شائعة

**ماذا لو لم أنزّل نموذج LaMa؟**
يعمل البرنامج بمسح أبسط (OpenCV). النتيجة ممتازة في الفقاعات البيضاء، وأقل جودة فوق الرسم المعقد.

**كم يستغرق تثبيت المكتبات؟** من 2 إلى 5 دقائق. لا يحتاج PyTorch ولا بطاقة شاشة قوية.

**التحميل عند أول تشغيل:** يثبّت البرنامج المكتبات وينزّل نموذج المسح الذكي (~200 ميغابايت) تلقائيًا قبل أن يبدأ. إن لم يتوفر إنترنت يبدأ بالمسح البسيط ويمكنك تنزيله لاحقًا من Setup.

**سرعة الصفحة؟** غالبًا بضع ثوانٍ للصفحة على معالج عادي. كل نصوص الصفحة تُرسل لجوجل في طلب واحد فقط (بدون إغراق الخدمة)، والقراءة والترجمة تعملان بالتوازي مع المسح.

**نصوص الحقوق والمواقع (مثل «اقرأ الفصل على site.com»)؟** يكتشفها البرنامج تلقائيًا فيمسحها بدون ترجمة، وتظهر في قائمة الكتل بوسم `[credit]`. يمكنك إيقاف ذلك من تبويب Translation، أو تعليم/إلغاء تعليم أي كتلة يدويًا من تبويب Blocks.

**النص الطويل يخرج من الفقاعة؟** يُضبط حجم الخط وتقسيم الأسطر حسب شكل الفقاعة البيضاوي، فلا يلمس حافتها. وإن بقي ضيقًا اختصر الترجمة يدويًا من تبويب Blocks.

**الخط العربي شكله عادي؟** الخط المرفق مؤقت. ضع خطوط عربية (ttf/otf) في مجلد `fonts` أو زر **Add font file** في تبويب Fonts & Style. مواقع مثل fonts.google.com فيها خطوط عربية مجانية.

**ظهرت رسالة أن Python بلا Tk (لينكس/ماك)؟**
أوبونتو: `sudo apt install python3-tk` · فيدورا: `sudo dnf install python3-tkinter` · ماك (Homebrew): `brew install python-tk`

**السحب والإفلات لا يعمل؟** افتح Setup وتأكد أن «Drag & drop support» عليه ✔، ثم أعد تشغيل البرنامج. وعلى لينكس قد لا يعمل مع بعض بيئات سطح المكتب، فاستخدم **Add Images**.

**كيف أرجع لتعديل صفحة لاحقًا؟** اضغط **Save project** ثم **Open project** وافتح ملف `.json`.

## 💻 للمتقدمين (سطر الأوامر)

```bash
python run.py cli صفحة.png -o output
python run.py cli مجلد_الفصل/ -o output --provider "MyMemory (free)"
python run.py cli --download-models      # تنزيل LaMa
python run.py cli --help
```

الأوامر التي تبدأ بـ `python run.py` تُثبّت المكتبات الناقصة تلقائيًا إن وُجدت.
